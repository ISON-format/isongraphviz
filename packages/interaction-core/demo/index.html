Input layer demo

Non-normative demo of interaction-core (IGR-IA/1). A headless renderer holds the semantic state; a tiny painter draws it on a canvas; bindInteraction turns the pointer, the wheel and the keyboard into the frozen IGR/1 intents. Click, shift-click, ctrl-click, drag to pan, alt-drag to lasso, wheel to zoom, double-click to fit; Tab into the box, then arrows, Home, End, PageUp, PageDown, e, s, t, Space, m (marquee: move, Enter), Escape, ctrl+a. There is no accessible companion here (that is a later package), so this page is not claimed accessible. Build with npm run demo -- ../../fixtures/oracles-ia/scenes/G9.scene.json ../../fixtures/oracles-ia/layouts/G9.layout.json --page and npm run demo:build, then serve this folder from localhost (hashing needs a secure context).
