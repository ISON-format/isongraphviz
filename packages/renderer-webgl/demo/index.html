Non-normative demo of the IGR-GL/1 WebGL2 renderer. Source text, scene and layout are embedded by scripts/plan-ison.mjs --demo; the plan is drawn by the six shaders through a real WebGL2 context and the labels by the companion 2D layer. The page probes for WebGL2 first and, when the probe refuses, mounts the Canvas renderer and then V5's SVG renderer by the host's own try-chain (fallback is never the renderer's). A click goes through pickDrawn and shows the typed address and the identity that resolveSelection finds in the embedded source. Build once with npm run demo -- ../../fixtures/oracles/o1-basic.source.ison --demo --layout force and npm run demo:build, then serve this folder from localhost (hashing needs a secure context); add ?software=1 to accept software GL. The canvas is not keyboard-operable and is not claimed accessible (design 8.3).
