Click to source address

Non-normative demo of the IGR-CV/1 Canvas renderer. Source text, scene and layout are embedded by scripts/render-ison.mjs --demo; the display list is painted on a canvas by the 2D replay. A click goes through pickDrawn (so a self-loop and every parallel member are reachable) and shows the typed address and the identity that resolveSelection finds in the embedded source. Build once with npm run demo -- ../../fixtures/oracles/o1-basic.source.ison --demo --layout force and npm run demo:build, then serve this folder from localhost (hashing needs a secure context). The canvas is not keyboard-operable and is not claimed accessible (design 8.3).
